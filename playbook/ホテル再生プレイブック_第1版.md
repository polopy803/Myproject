## 前提: 再生の基本スキーム(実績)

- **所有と運営を分離する。** 物件はキンキエステート等が取得し、運営会社(Now Resort / ホテルファミリア)が賃借して運営する。太田(賃貸)・高萩(改装後賃貸or買取)・旭(運営会社ごと買収)の3パターンを実施済み。(出典: プロフィール)
- **初期はハンズオン。** 支配人・総支配人として現場に入り、黒字化後に「自走できるホテル」へ移行する。2026年の目標は「①高萩開業 ②青森開業 ③千葉(旭)自走化 ④太田自走化」。(出典: ジャーナリング2026-04-24)
- **出口を最初に決める。** 太田は「再生して会社を1億円で売却、キンキとしても簿価回収」を目標に設定していた。(出典: 自分ノート)

# フェーズ0: 取得判断

## 0-1. 需要の裏取り(実績ベース)

- **地域の産業需要を特定してから買う。** 旭は鹿島工業団地の3年に一度の定期修繕で5-6月が満室級に埋まった。逆に風力発電(三菱)撤退で駅前ビジネスホテル全体の稼働が下がった実例もある。(出典: 議事録2026-06-09, 2026-04-21)
  - **判断基準:** 需要の柱が特定の1産業・1工場なら、その撤退リスクを織り込む。柱が「定期修繕・工事」なら周期(毎年か3年毎か)を確認する。
- **競合の新規開業予定を必ず調べる。** ルートイン開業の影響は「直後は1〜2%、時間経過とともに拡大」が実測値。ドーミーイン開業も注視対象になった。(出典: 議事録2026-04-21, 2026-06-09)
  - **判断基準:** 商圏内に大手チェーンの開業予定があるなら、初年度でなく2〜3年目の稼働率で収支を引き直す。
- **コンセプトは「宿泊導線の内側」で作る。** 高萩は「駅前立地の大浴場付きビジネスホテル。宿泊者の入浴需要を内包。出張客にとって移動なしで整う」と定義した。(出典: 補助金計画書)

## 0-2. DDチェックリスト(すべて実績由来の地雷)

**財務・契約**
- [ ] 決算書3年分 + 仕訳データ + 支払手数料の内訳明細(外注費との区分)。沖縄案件で最初に要求したセット。(出典: 議事録2026-05-29)
- [ ] OTA依存度と送客手数料率。楽天1位・手数料23〜25%が沖縄の実態だった。
- [ ] 法人特約の全リスト。太田では引き継ぎ後に**9割解約**した=不採算特約が大量に眠っている前提で見る。(出典: 太田ナウ改革実績)
- [ ] 割引の重複適用ルール。早割×メルマガ割の重複で通常価格から40%引き(9,000円)になっていた事故あり。(出典: 議事録2026-05-29)
- [ ] リース・保守契約の棚卸し: VOD、カルミック(芳香剤)、ALSOK等。太田ではいずれも解約・買い取りで削減した。
- [ ] 清掃契約の単価と稼働率保証の有無。旭は「750円+稼働率保証58%」→「900円・保証なし」の切替経緯があり、低稼働月は清掃側が赤字になる構造だった。(出典: 議事録2026-04-21)
- [ ] 会計が現金主義になっていないか。**ホテルは現預金が先に入るため経営状態を錯覚しやすい。発生主義で引き直して家賃を引いたら赤字、が千葉の実例。**(出典: 議事録2026-06-17)

**設備**
- [ ] エアコンの系統と故障室数(太田・旭とも修理で販売可能室が約10室単位で変動した)
- [ ] ボイラー方式(長野物件では個別ガス化への切替を長期計画に入れた)
- [ ] 雨漏り(高萩は購入直後の台風でサッシから雨漏り発生)
- [ ] 消防: 2方向避難(旭は朝食スペースが非常口に該当し消防と調整中)、カーペットの防炎タグ(太田で入替時にタグなし発覚)
- [ ] 開かない窓・喫煙所の換気(いずれも太田・旭で事後対応した)

**権利関係・データ**
- [ ] 駐車場の権利。旭は隣接スーパーの駐車場を黙認利用しており、書面化が課題になった。
- [ ] 無償利用者の有無。旭は4階旧客室をロータリークラブが倉庫・例会所として使用していた。
- [ ] 顧客データの有無。旭は前管理者がデータを消去しており、倉庫の紙資料から宴会顧客を復元する羽目になった。**引き継ぎ交渉時点で顧客データの引渡しを契約に入れる。**(出典: 議事録2026-06-19)

## 0-3. 値付けと撤退基準

- **入札は競合想定より刻んで勝ちにいかない。** 千葉寄宿舎は競合1億2,000万に対し1億900万で落札。出口は「1年以内・利回り8〜9%(約2億5,000万)で売却」と先に決めた。(出典: 議事録2026-06-09)
- **判断基準(仮説):** 取得時点で「◯年以内に利回り◯%で売却 or 自走化して保有」の出口を書面化できないなら、買わない。
- 【要確認】買収の投資上限・回収年数・最低利回りの明文化された基準は記録に見当たらない。千葉寄宿舎の「利回り8〜9%」が唯一の数値実績。

# フェーズ1: 引継ぎ〜30日

## 1-1. 最初にやること(実績)

1. **ごみを捨てまくる。** 太田では倉庫・チャペル・別館3階・6階を徹底的に空けた。改革実績リストの筆頭項目。スペースが空くと後の改装(パーティールーム化等)の選択肢が生まれる。(出典: 太田ナウ改革実績)
2. **現金と会計の実態把握。** freee導入、請求書もfreeeで発行。発生主義で締め直す。
   - **判断基準:** 引き継ぎ直後に「思ったより儲かっている」ように見えたら、現金先行の錯覚を疑い、発生主義+家賃控除後で検算する。(出典: 議事録2026-06-17)
3. **契約の棚卸しと即時解約。** VODリース終了→テレビ/ネットリプレイス、カルミック解約→市販芳香剤、ALSOK解約→カメラ買い取り+TAPO設置、従業員用自販機(会社負担)撤去。(出典: 太田ナウ改革実績)
   - **判断基準:** 月額契約で「代替品を買い切りにできるもの」なら、違約金と比較して即解約する。
4. **人の把握と最小限の組織変更。** 太田は従業員を引き継ぎ、キーパーキャプテン制→リーダー制に格下げ、キーパーをフロント直下に所属させた(指揮系統の一本化)。(出典: 太田ナウ改革実績)
5. **日次の情報ラインを引く。** Notion=ストック(引き継ぎ・修繕・予約DB)、Discord=フロー(日報・リアクション)。朝礼を定時で入れる(高萩は毎朝10:00)。(出典: 議事録2026-06-23, カレンダー)

## 1-2. 最初の30日でやらないこと(実績)

- **新規事業に手を出さない。** 弁当販売・近隣店舗コラボ等は指示系統が錯綜した経緯があり、「まず本業(宿泊・宴会)の稼働率向上と高単価化に集中する」と決めた。(出典: 議事録2026-06-19)
- **大型設備投資をしない。** 絨毯クリーニング・高圧洗浄などは全館空調(2,000〜3,000万)の予算確定後に後回しした。客室に直結する投資を優先。(出典: 議事録2026-04-21)
- **判断基準:** 独断で採用・昇給を約束するキーパーソンがいるなら、対決せず業務範囲を1領域(旭の例では設備修繕)に限定する調整を、本人の上位者(会長)経由で行う。(出典: 議事録2026-06-09)

## 1-3. リスク事象への備え

- 太田では死亡事故、デリヘル・ホテヘル利用が実際に発生している。(出典: 太田ナウ改革実績)
- 【要確認】これらの対応手順(警察・保険・家族対応・客室復旧)は文書化されていない。第2版で危機対応SOPとして起こす。

# フェーズ2: 31日〜100日

## 2-1. 価格改定(順序: 特約整理 → 重複排除 → 日別コントロール → 値上げ)

1. **不採算の法人特約を解約する。** 太田は9割解約。(出典: 太田ナウ改革実績)
   - 【要確認】「解約する/残す」の判定ライン(単価いくら以下なら切る等)は記録なし。
2. **法人割引は固定額から率に変える。** 旭では単価が1万円前後に上がった結果、固定1,000円引きが機能しなくなり「販売価格の10%引き」へ変更。電話受けの法人特約価格は自社予約エンジン稼働に合わせて廃止方向。(出典: 議事録2026-06-19)
   - **判断基準:** ADRが上昇局面に入ったら、固定額割引は率割引に置き換える。
3. **割引の重複適用を禁止する。** 沖縄の40%引き事故を教訓に、割引は排他適用にする。宿泊・宴会の法人割引併用問い合わせも「どちらか一方」で運用。(出典: 議事録2026-05-29, 2026-06-19)
4. **日別料金コントロール。** 予約集中日は値上げ。現状スプレッドシート管理で機能している。(出典: 議事録2026-06-19)
5. **販売チャネルの組み替え。** PMS入替(BIZ→Staysee)、宿力(撮影・プラン作成・レベニュー)、Tripla自社予約エンジン導入。OTA手数料23〜25%を踏まえ、**評価指標は売上ではなく「売上−送客手数料−決済手数料」の粗利**で見る。(出典: 太田ナウ改革実績, 議事録2026-05-29)
6. **撮影とプラン整備は値上げとセット。** 沖縄・旭とも「写真撮影→HP/プラン→価格」の順で走らせている。写真は一品ずつ・背景なし、白皿より映える器(100均可)。(出典: 議事録2026-06-19)

## 2-2. 宴会テコ入れ(実績: 旭)

- **松竹梅は竹に誘導する設計。** 上位コースほど利益率が高い設計にする。料理外注費が約70%なので、**コース単価が上がるほどほぼそのまま利益になる。**(出典: 議事録2026-06-17)
- **宴会の空き日は5,000円級の廉価プランで稼働を埋める。**(出典: 議事録2026-06-19)
- **休眠顧客を掘り起こす。** 過去宴会利用者へDM(データがなければ紙資料から復元)。同窓会は閑散期(8月)を支える重要客層としてリピーター化。(出典: 議事録2026-06-19)
- **判断基準:** 地域で大型宴会場を持つ競合が減っているなら(旭は取り壊しが進行中)、宴会は縮小でなく攻めの投資対象にする。
- **顧客担当者へのキャッシュバック系インセンティブは、担当者が2〜3年で交代する企業には効果が薄い**ためやらない。(出典: 議事録2026-06-17)

## 2-3. 経費削減(実績: 太田)

- サービス朝食→有料化 / 高級アメニティ削減(法外なハンド・フェイスウォッシュ、国産歯ブラシ→ベトナム産) / アメニティは1階集約 / LED化(電球・シーリング) / 玄関マットを名入りからダスキンへ。(出典: 太田ナウ改革実績)
- **判断基準:** 削減は「客が選定理由にしない項目」から。大浴場・朝食の質など予約理由になる項目は削らず、むしろ値上げ原資として強化する(旭では朝食レベルアップ+値上げを検討)。(仮説を含む)

## 2-4. 100日時点の投資判断

- 補助金を投資に組み込む。太田は持続化補助金でスイートルーム+プライベートサウナ、事業再構築系の実例(キャンプ場2,500万)も観測済み。新事業進出補助金は高萩で申請実績。(出典: 太田ナウ改革実績, 議事録2026-05-29, 補助金計画書)
- **判断基準:** 自己資金だけで回収3年超の改装は、対応する補助金の公募スケジュールを先に確認してから着手する。(仮説)

# フェーズ3: 定常運営への移行(自走化)

## 3-1. 情報基盤の導入手順(実績: 太田フロントで稼働中)

1. **フロント引き継ぎDB**: 手書きメモ・ポストイットをNotionへ。有効期間・完了ステータス付き。過去メモをコピペ再利用できる形で蓄積。
2. **朝食仕込み量DB**: 有効期限・完了ステータス付き。
3. **宴会・会議室予約、団体宿泊予約DB**。
4. **設備故障・修繕DB**: Excelから移行、進捗ステータス管理。
5. **Discord=フロー / Notion=ストック**の使い分け。日報はDiscord(スマホ閲覧・リアクションが楽)。
(出典: 議事録2026-06-23)
- コスト制約: 1人あたりGoogle+Notionで約5,000円/月かかるため、共有ビジネスアカウント+タグで担当者区別が現実解。経営機密は個人アカウント側に分離。(出典: 議事録2026-06-23)

## 3-2. バックオフィスの型(実績)

- 勤怠: タイムカード→King of Time / 会計・請求書: freee / 賞与年2回(1か月分ずつ)で処遇を安定させる。(出典: 太田ナウ改革実績)
- 部門別損益: 家賃・電気代・消防点検費等の固定費按分基準を設定し、宴会部門の損益分岐点を明確にする。(出典: 議事録2026-06-19 — 現在進行中)

## 3-3. 人と権限(実績)

- **やる気のある人に現場権限を渡す。** 権限移譲がモチベーションと成長の鍵。(出典: 議事録2026-06-17)
- 実例: 元従業員の川村さんが京都ホテルの社長に就任予定。若手(20歳)にインスタ運用を本格移管。(出典: 議事録2026-05-29, 2026-06-19)
- **判断基準:** 自分が2週間現場を離れても回る状態を「自走化」と定義し、それまで支配人業務を手放さない。(仮説 — 「自走できるホテルをつくる」の運用定義として提案)

## 3-4. 外部委託の型(実績)

- 団体・宴会の食事は撤退前オペレーター(ルセット福田さん)に業務委託 — 前運営者を敵にせず戦力化した例。(出典: 太田ナウ改革実績)
- 夕食は自社提供せず、周辺飲食店の夕食券(2,000円分)をセットプラン化して地域と連携。(出典: 議事録2026-06-09)

# 【要確認】一覧(第2版までに埋める)

1. **撤退基準の明文化** — 「買わない条件」「損切り条件」の数値基準。現状は千葉寄宿舎の出口利回り8〜9%のみ。
2. **太田の現在の稼働率・ADR・GOP実数** — 改革前後の比較表を作れば、コンサル営業資料としてそのまま使える。
3. **GOPの定義と目標値** — 家賃・按分固定費をどう扱うか(6/19時点で固定費按分基準が未整理)。
